일반적인 과정

A) 일정에 맞는 운행가능 차량목록 조회
B) 차량 선택 후 기타 운행정보 입력
C) 신청 후 운행 일정 목록에서 신청내용(특히 주차위치) 확인
D) 운행 종료 후 주차위치 작성

# A
DONE - 시작일, 종료일 선택 시 (+오전, 오후) 수정된 일자에 맞게 차량예약 차량목록 그리드 리로딩
DONE - 시작 종료 동일 버튼 클릭 시 시작일 관련 정보를 종료일에 동일하게 적용
DONE - 그리드에서 주차위치 컬럼 삭제

# B
DONE - 차량예약 차량목록 그리드 클릭 시 차량예약 정보입력 모달창 팝업
DONE - 모달창에 정보입력 후 저장 시 정보저장
DONE - 정보 저장 시 tb_car_book_schedule 테이블에만 저장(th_car_book에는 주차위치 저장하면 넘기기)

# C
DONE - 운행 일정 그리드 컬럼 수정(주차기록, 차량번호, 차량모델, 운전자,
    현재주차위치(tb_park_loc), 해당차량 이전 신청자명(th_car_book 조건검색), 시작일, 종료일)


# D
DONE - 그리드 클릭 시 모달창 표출 -> 운행일정 처리
    1) 미운행 / 운행 선택
    2) 주차위치 입력(운행 시에만 입력, 미입력 시 저장불가)
    3) 저장 시 tb_car_book_schd에서 삭제, th_car_book에 저장(th_car_book REQ_TYPE -> 운행여부로 변경)
DONE - 종료일이 지났지만 주차기록이 되지않은 항목에 적색으로 처리

####
DONE - 종료일이 지났지만 주차기록이 되지않은 이력을 발견하면 토스트알럿 발생구현
DONE - 로그아웃
DONE - URL 이동 시 등급검증
