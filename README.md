# 차량 예약 시스템

**React / TypeScript** 기반의 차량 예약 시스템

법인 차량을 사용하는 직원들이 담당자의 수동 배정 없이 직접 예약 내역을 확인하고 신청할 수 있도록 하여

담당자의 **반복 업무를 줄이고** 직원들의 차량 **사용 편의성을 높이기** 위해 개발한 프로젝트 입니다.

## 개발기간
2024.09. ~ 2024.12.

## 주요기능
- 예약 가능 차량 목록 조회
- 차량 예약 신청/조회/수정/취소
- 주차 위치 등록 / 미등록 시 알람
- [관리자] 전체 운행 일정/기록 조회 및 관리
- [관리자] 차량/사용자 관리

## 사용기술
- React 18.3
- TypeScript 5.5
- Vite 5.4
- GitHub
