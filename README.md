# 차량 예약 시스템

**React / TypeScript** 기반의 차량 예약 시스템

법인 차량을 사용하는 직원들이 담당자의 수동 배정 없이 직접 예약 내역을 확인하고 신청할 수 있도록 하여
담당자의 **반복 업무를 줄이고** 직원들의 차량 **사용 편의성을 높이기** 위해 개발한 프로젝트 입니다.

## 📆 개발기간
2024.09. ~ 2024.12.

## 🧩 주요기능
- **예약 가능 차량 목록 및 차량 일정표 조회**
  - 사용자의 예약 신청 시점 기준으로, 해당 시간에 사용 가능한 차량만 필터링하여 목록 제공
  - 주차위치가 정상적으로 등록되어 있는 차량 필터링
  - 주 단위로 차량의 예약 일정표 조회

- **차량 예약 신청/조회/수정**
  - 사용할 날짜와 시간을 선택해 사용 가능한 차량 목록에서 예약 신청
  - 예약 후에는 내역을 확인하거나 일정과 차량을 제외한 내용 변경
  - 취소 기능 대신 미운행 여부를 추가해 운행 일정 기록

- **주차 위치 등록 / 미등록 시 알람**
  - 주차 위치 등록 기능으로 운행 완료 여부를 판단
  - 미등록 시 다음 사용자에게 혼선을 줄 수 있어 별도의 알림 제공
  - 예약 차량의 주차 위치가 미등록된 경우 이전 사용자 정보를 제공

- **시스템 관리자 페이지**
    - 전체 예약 현황, 운행 기록, 주차 위치 미등록 예약 정보 조회
    - 차량 정보(번호, 차종, 연료 등) 등록/수정/삭제 기능
    - 사용자 목록 조회, 권한(관리자/사용자) 및 사용 제한 기능
